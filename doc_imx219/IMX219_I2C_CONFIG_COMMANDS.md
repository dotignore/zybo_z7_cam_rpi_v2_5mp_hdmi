# IMX219 — I2C команды конфигурации

Источник: `src/imx219.c`, datasheet Quectel IMX219, Linux/RPi driver.

Все настройки — один тип транзакции.

Режим проекта по умолчанию: **1920 × 1080, RAW10, 2-lane CSI-2, ~24 fps**.

## Общий формат команды

| Поле | Значение |
|------|----------|
| Шина | I2C |
| Slave address | `0x10` (alt `0x1A`) |
| Тип | **Register Write** |
| Адрес регистра | 16 bit (big-endian на шине) |
| Данные | 8 bit |

Байтовая последовательность write:

```
[reg_hi] [reg_lo] [data]
```

Пример: `0x018C = 0x0A` → `01 8C 0A`

В коде проекта: `Imx219_WriteReg(Iic, reg, val)`.

16-bit значения пишутся двумя write: старший байт, затем младший.

### Пример для 1920 × 1080

Формат команд не меняется — всегда:

```
I2C WRITE @ 0x10 :  [reg_hi] [reg_lo] [data]
```

Ниже у каждой секции — конкретные байты именно для режима 1920×1080 из `src/imx219.c`.

## 1. DT / формат выхода (RAW10 / RAW8 / COMP8)

| | |
|--|--|
| Команда | I2C Write ×2 |
| Регистры | `0x018C`, `0x018D` (`CSI_DATA_FORMAT_A`) |
| Формат | `WR 018C=hi`, `WR 018D=lo` |

| Режим | 018C | 018D | CSI DT |
|-------|------|------|--------|
| RAW10 | `0x0A` | `0x0A` | `0x2B` |
| RAW8  | `0x08` | `0x08` | `0x2A` |
| COMP8 | 8-bit compressed (семейство RAW8) | | как RAW8 |

В проекте: `{0x018C,0x0A},{0x018D,0x0A}` → RAW10.

### Пример для 1920 × 1080 → RAW10

```
01 8C 0A
01 8D 0A
```

Смысл: CSI DT на проводе = `0x2B`, WC = 1920×10/8 = **2400** байт/строка.

## 2. Разрешение кадра (crop + output + binning)

| | |
|--|--|
| Команда | I2C Write, таблица регистров |
| Формат каждого 16-bit поля | `[15:8]` затем `[7:0]` |

| Параметр | Регистры | У вас (1080p) |
|----------|----------|----------------|
| X start | `0x0164/0165` | 680 (`0x02A8`) |
| X end | `0x0166/0167` | 2599 (`0x0A27`) |
| Y start | `0x0168/0169` | 692 (`0x02B4`) |
| Y end | `0x016A/016B` | 1771 (`0x06EB`) |
| X_OUT | `0x016C/016D` | 1920 (`0x0780`) |
| Y_OUT | `0x016E/016F` | 1080 (`0x0438`) |
| X_ODD_INC | `0x0170` | `0x01` |
| Y_ODD_INC | `0x0171` | `0x01` |
| BINNING_H | `0x0174` | `0x00` (off) |
| BINNING_V | `0x0175` | `0x00` (off) |

Типовые режимы (меняются те же регистры + timing/PLL):

- 3280×2464 (full)
- 1920×1080 (ваш)
- 1280×720
- 640×480

Таблица: `imx219_1080p_regs[]` в `src/imx219.c`.

### Пример для 1920 × 1080 (центр crop, без binning)

```
# crop X 680..2599

01 65 A8
01 66 0A
01 67 27

# crop Y 692..1771
01 68 02
01 69 B4
01 6A 06
01 6B EB

# output size 1920 x 1080
01 6C 07
01 6D 80
01 6E 04
01 6F 38

# no binning
01 70 01
01 71 01
01 74 00
01 75 00
```

## Связь с CSI-2 на проводе

После `CSI_DATA_FORMAT=0x0A0A` сенсор сам шлёт long packets с:

- DT = `0x2B` (RAW10)
- WC = `X_OUT × 10 / 8` (= 2400 при 1920)

Маркеры кадра/строки (short packets): FS=`0x00`, FE=`0x01`, LS=`0x02`, LE=`0x03`.

### Пример для 1920 × 1080 на проводе

```
FS (DT=0x00)
  ×1080 long packets: DT=0x2B RAW10, WC=2400
FE (DT=0x01)
```

## MIPI CSI-2 — структура пакетов и Data Types

### Short Packet (4 байта, без payload)

```
Byte 0: [VC(2b) | DT(6b)]
Byte 1: Data[7:0]
Byte 2: Data[15:8]
Byte 3: ECC(8b)
```

| DT (hex) | Тип | Data field | IMX219 шлёт? |
|----------|-----|-----------|-------------|
| `0x00` | **Frame Start (FS)** | Frame number | ✅ да |
| `0x01` | **Frame End (FE)** | Frame number | ✅ да |
| `0x02` | **Line Start (LS)** | Line number | ❌ нет (выключено) |
| `0x03` | **Line End (LE)** | Line number | ❌ нет (выключено) |
| `0x08`–`0x0F` | Generic Short 1–8 | произвольные | ❌ нет |

### Long Packet (заголовок + payload + CRC)

```
Byte 0:   [VC(2b) | DT(6b)]
Byte 1:   WC[7:0]          ← Word Count (байт payload)
Byte 2:   WC[15:8]
Byte 3:   ECC(8b)
Byte 4…N: payload (WC байт)
Byte N+1: CRC[7:0]
Byte N+2: CRC[15:8]
```

| DT (hex) | Тип | WC | IMX219 шлёт? |
|----------|-----|----|-------------|
| `0x12` | Embedded 8-bit (статистика AE/AWB) | переменный | ⚙️ опционально (`0x0238/0239`) |
| `0x2A` | RAW8 | X_OUT × 1 | только если CSI_DATA_FORMAT=0x0808 |
| **`0x2B`** | **RAW10** | **X_OUT × 10 / 8** | ✅ **наш режим** |
| `0x2C` | RAW12 | X_OUT × 12 / 8 | нет |

### Параметры для режима 1920 × 1080 RAW10

| Параметр | Значение |
|----------|---------|
| DT строки | `0x2B` |
| WC (Word Count) | **2400** байт / строка (1920 × 10 / 8) |
| Строк на кадр | **1080** |
| VC | `0x00` (один сенсор) |

### Полная временна́я диаграмма кадра

```
FS  short packet  DT=0x00  Data=frame_number
│
├─ line 0    long packet  DT=0x2B  WC=2400  payload(RAW10)  CRC
├─ line 1    long packet  DT=0x2B  WC=2400  payload(RAW10)  CRC
├─ ...
├─ line 1079 long packet  DT=0x2B  WC=2400  payload(RAW10)  CRC
│
FE  short packet  DT=0x01  Data=frame_number
```

### RAW10 упаковка на проводе (5 байт = 4 пикселя)

```
Byte 0: px0[9:2]
Byte 1: px1[9:2]
Byte 2: px2[9:2]
Byte 3: px3[9:2]
Byte 4: px3[1:0] | px2[1:0] | px1[1:0] | px0[1:0]
```

→ WC = 1920 × 10 / 8 = 2400 байт = 480 групп по 5 байт = 1920 пикселей.

### После VFB IP (AXI Stream → VDMA)

VFB распаковывает RAW10 → 16-bit little-endian, один пиксель = 2 байта:

```
На проводе (5 байт = 4 px):   C4 C2 C1 C0 xx
После VFB (8 байт = 4 px):    C0 00  C2 00  C1 00  C0 00   ← u16LE
```

| Параметр | На проводе | После VFB |
|----------|-----------|----------|
| Байт / строка | 2400 | **3840** (1920 × 2) |
| Тип | RAW10 packed | u16 LE (10-bit в [9:0]) |
| VDMA HSIZE | — | **3840** |
| VDMA VSIZE | — | **1088** (1080 + 8 запас) |

Пример из дампа (line 0, первые 8 пикселей):

```
44 00  41 00  42 00  41 00  42 00  41 00  43 00  40 00
= 0x44 0x41  0x42  0x41  0x42  0x41  0x43  0x40
=  68   65    66    65    66    65    67    64   (dec, 10-bit Bayer)
```
